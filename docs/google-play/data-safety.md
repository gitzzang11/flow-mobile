# Play Console Data safety 권장 답변

이 답변은 현재 코드에 서버 통신, 광고, 분석 SDK 및 `INTERNET` 권한이 없다는 전제입니다. SDK나 기능이 바뀌면 다시 검토해야 합니다.

| 질문 | 권장 답변 | 근거 |
|---|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 아니요 | 데이터가 개발자 또는 제3자 서버로 전송되지 않음 |
| 수집된 모든 사용자 데이터가 전송 중 암호화되나요? | 해당 없음 | 개발자 수집이 없음 |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 서버 계정/데이터 없음 | 앱 내 전체 삭제, OS 앱 데이터 삭제, 앱 제거로 로컬 삭제 |
| 광고가 포함되나요? | 아니요 | 광고 SDK 없음 |

## 기능별 판단

- 프롬프트·폴더·태그: 기기 안에서만 저장되므로 개발자의 “수집”에 해당하지 않음.
- 선택 사진: 시스템 선택기를 통해 사용자가 고른 사진만 로컬 처리하므로 사진/동영상 수집으로 신고하지 않음.
- 생체인증: OS 인증 결과만 사용하며 생체 원본이나 템플릿을 받지 않으므로 생체정보 수집으로 신고하지 않음.
- 사용자가 실행하는 공유/JSON 내보내기: 개발자에게 전송되지 않으므로 개발자 수집·공유로 신고하지 않음. 다만 선택한 외부 서비스가 파일을 처리할 수 있음을 개인정보처리방침에 명시.

## 제출 직전 재확인

- 최종 AAB의 병합 Manifest에 `INTERNET`, 광고 ID, 광범위 저장소/미디어 권한이 없는지 확인.
- 새 SDK가 네트워크 통신 또는 진단 데이터를 보내지 않는지 확인.
- Play Console 질문 문구가 변경되면 현재 문구 기준으로 다시 매핑.
