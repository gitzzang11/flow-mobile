# Flow 개인정보처리방침

시행일: 2026년 8월 17일

Flow(이하 “앱”)는 사용자의 프롬프트를 기기 안에서 정리하고 보관하는 앱입니다. 앱 개발자는 사용자의 프롬프트, 폴더, 태그, 첨부 이미지 또는 생체정보를 개발자 서버로 수집하거나 전송하지 않습니다.

## 1. 수집하는 개인정보

앱은 계정을 만들지 않으며, 개발자 서버를 운영하지 않습니다. 광고 및 이용 분석 SDK도 포함하지 않습니다. 따라서 개발자가 수집하거나 제3자와 공유하는 사용자 데이터는 없습니다.

## 2. 기기 내 저장 정보

프롬프트, 폴더, 태그, 앱 설정과 사용자가 선택한 이미지는 앱의 전용 기기 저장공간에 저장됩니다. 이 정보는 앱 기능 제공을 위해 기기 안에서만 처리되며 개발자에게 전송되지 않습니다.

앱 잠금 PIN 원문은 저장하지 않습니다. PIN 검증용 해시와 salt는 운영체제가 제공하는 보안 저장소에 저장됩니다. PIN 및 생체인증은 앱 접근을 제한하는 기능이며, 저장된 프롬프트 전체가 PIN으로 암호화된다는 의미는 아닙니다.

## 3. 생체인증

생체인증은 Android 또는 iOS의 운영체제 인증 기능을 사용합니다. 앱은 지문·얼굴 원본이나 생체 템플릿을 직접 수집, 저장 또는 전송하지 않으며 인증 성공 여부만 전달받습니다.

## 4. 사진 선택

사용자가 명시적으로 선택한 이미지만 앱에 첨부할 수 있습니다. 선택한 이미지는 앱 전용 저장공간에 복사되어 기기 안에서 처리되며 개발자 서버로 전송되지 않습니다.

## 5. 백업과 공유

사용자가 “백업 내보내기”를 실행하면 프롬프트, 폴더, 태그와 첨부 이미지가 암호화되지 않은 JSON 백업 파일에 포함될 수 있습니다. PIN 원문, PIN 해시 및 salt는 백업에 포함되지 않습니다.

백업 또는 프롬프트 공유 시 사용자가 선택한 외부 앱이나 서비스로 데이터가 전달될 수 있습니다. 해당 외부 서비스의 데이터 처리는 그 서비스의 개인정보처리방침을 따릅니다.

## 6. 보관 및 삭제

앱 데이터는 사용자의 기기에 보관됩니다. 설정의 “전체 데이터 삭제”를 사용하거나 운영체제 설정에서 앱 데이터를 삭제하거나 앱을 제거하여 삭제할 수 있습니다. 공유 후 임시 백업 파일은 가능한 즉시 삭제되며, 남은 임시 파일은 이후 앱 실행 시 정리됩니다.

## 7. 자동 백업

앱은 Android 시스템의 클라우드 자동 백업 및 기기 간 앱 데이터 전송 대상에서 앱 데이터를 제외하도록 설정합니다. 사용자가 직접 실행하는 JSON 백업만 지원합니다.

## 8. 아동의 개인정보

앱은 특정 연령의 아동을 대상으로 설계되지 않았고 개인정보를 개발자 서버로 수집하지 않습니다. 보호자가 기기 내 데이터를 삭제하려면 위의 삭제 방법을 사용할 수 있습니다.

## 9. 방침 변경

기능 또는 법적 요구사항이 바뀌면 이 방침을 갱신하고 시행일을 변경합니다. 중요한 변경은 앱 또는 스토어 등록정보를 통해 알릴 수 있습니다.
