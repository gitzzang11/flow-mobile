Flow 개인정보처리방침

시행일: 2026년 8월 17일

Flow(이하 “앱”)는 사용자의 프롬프트를 기기 안에서 정리하고 보관하는 앱입니다. 앱 개발자는 사용자의 프롬프트, 폴더, 태그, 첨부 이미지 또는 생체정보를 개발자 서버로 수집하거나 전송하지 않습니다.

1. 수집하는 개인정보

앱은 계정을 만들지 않으며 개발자 서버를 운영하지 않습니다. 광고 및 이용 분석 SDK도 포함하지 않습니다. 따라서 개발자가 수집하거나 제3자와 공유하는 사용자 데이터는 없습니다.

2. 기기 내 저장 정보

프롬프트, 폴더, 태그, 앱 설정과 사용자가 선택한 이미지는 앱 전용 기기 저장공간에 저장되고 기기 안에서만 처리됩니다. PIN 원문은 저장하지 않으며 검증용 해시와 salt는 운영체제 보안 저장소에 저장됩니다. PIN 및 생체인증은 앱 접근을 제한하는 기능이며 저장된 콘텐츠 전체를 암호화하는 기능은 아닙니다.

3. 생체인증과 사진

생체인증은 운영체제가 처리하며 앱은 지문·얼굴 원본이나 생체 템플릿에 접근하지 않고 인증 성공 여부만 전달받습니다. 사용자가 명시적으로 선택한 이미지는 앱 전용 저장공간에 복사되어 기기 안에서 처리됩니다.

4. 백업과 공유

사용자가 백업을 내보내면 프롬프트, 폴더, 태그와 첨부 이미지가 암호화되지 않은 JSON 파일에 포함될 수 있습니다. PIN 원문, PIN 해시 및 salt는 포함되지 않습니다. 사용자가 선택한 외부 앱이나 서비스로 공유한 데이터는 해당 서비스의 개인정보처리방침에 따라 처리될 수 있습니다.

5. 보관 및 삭제

설정의 “전체 데이터 삭제”, 운영체제의 앱 데이터 삭제 또는 앱 제거를 통해 기기 내 정보를 삭제할 수 있습니다. 공유용 임시 백업은 가능한 즉시 삭제하며 남은 파일은 이후 앱 실행 시 정리합니다. Android 자동 백업과 기기 간 앱 데이터 전송에서는 앱 데이터를 제외합니다.

6. 아동, 변경 및 문의

앱은 특정 연령의 아동을 대상으로 설계되지 않았고 데이터를 개발자 서버로 수집하지 않습니다. 기능 또는 법적 요구사항이 바뀌면 이 방침과 시행일을 갱신합니다.
