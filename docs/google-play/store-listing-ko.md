# Google Play 스토어 등록정보 — 한국어

## 앱 이름

Flow

## 간단한 설명

나만의 AI 프롬프트를 빠르게 저장하고 정리하는 로컬 보관함

## 자세한 설명

자주 쓰는 AI 프롬프트, 이제 찾느라 시간을 쓰지 마세요.

Flow는 프롬프트를 폴더와 태그로 정리하고 필요한 순간 빠르게 찾아 복사할 수 있는 로컬 프롬프트 보관함입니다. 계정 가입 없이 바로 시작하고, 작성한 내용은 기본적으로 내 기기 안에 보관됩니다.

주요 기능

• 프롬프트 작성, 수정, 검색
• 폴더와 태그를 활용한 체계적인 정리
• 자주 쓰는 프롬프트 고정과 정렬
• 텍스트 구간별 색상으로 핵심 내용 구분
• 선택한 이미지 첨부
• 한 번의 탭으로 복사 또는 공유
• JSON 백업 내보내기와 복원
• PIN 및 기기 생체인증을 이용한 앱 접근 제한
• 다크 모드와 카드 글자 크기 설정

Flow는 광고와 분석 SDK를 포함하지 않으며 개발자 서버로 프롬프트를 전송하지 않습니다. 백업과 공유는 사용자가 직접 실행할 때만 동작합니다.

중요: 내보낸 백업 파일에는 프롬프트와 첨부 이미지가 암호화되지 않은 상태로 포함될 수 있으므로 신뢰할 수 있는 위치에 보관하세요.

## 분류 제안

- 카테고리: 생산성
- 태그 후보: 메모 작성, 생산성, 도구
- 광고 포함: 아니요
- 앱 액세스: 로그인 또는 별도 접근 권한 불필요
- 대상 연령: 일반 사용자(아동 전용 앱 아님)
